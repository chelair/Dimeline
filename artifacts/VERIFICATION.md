## 测试覆盖

核心与组件测试包括严格日期、闰年、跨年、日期上限、日期坐标往返、重复缩放锚点、滚动、手动留白、DAG 前后向传播、多分支、锁定与范围冲突回滚、禁用/删除关联、确定性布局、框体碰撞、正交路径端点、文本尺寸、跨主线拖框、100/200 密集节点、100 步事务历史、脏状态、表单草稿、快捷键焦点、迁移、真实原子写入失败回滚、取消另存为及读取失败保留当前项目。

桌面自动化执行了以下流程：

1. 创建事件，编辑中文多行标题，保存，关闭，重启，重新加载并核对数据。
2. 拖动 A→B→C 日期链，检查联动；一次撤销恢复所有日期；Escape 取消预览；编辑焦点中 Backspace 不删除事件。
3. 水平滚动后围绕鼠标锚点放大缩小，锚点位置误差小于 2px；Alt 拖框保持日期；锁定布局后自动整理保持位置。
4. 关闭时选择保存但取消路径选择，窗口保持打开；写入失败也保持打开。
5. 新增关联先预览日期调整，确认后提交；反向关联形成循环时拒绝。
6. 真实生成四层级、中文多行、偏移和复杂箭头的完整 PNG；验证 PNG 签名及分辨率。放大和滚动后分别导出当前视口与完整图，验证像素尺寸。
7. 尚未失焦的标题触发关闭保护；选择保存后将草稿提交至真实文件，再关闭窗口。
8. 输入法 composition 期间 Enter 不错误提交；组合输入结束可提交；Escape 取消；右键移动框体；空格平移；深色主题。
9. 含链式依赖的 100 和 200 节点项目真实加载、渲染和缩放。
10. Vite 开发窗口真实创建事件，检查无页面异常。
11. Windows 打包程序启动，确认桥接 API 可用且冻结，页面不可访问 `require` 和 `process`，真实保存。

自动化为原生对话框提供确定的返回值和临时路径，文件系统、日期计算、React 界面、Electron IPC、窗口生命周期与导出编码均真实执行。生产文件服务没有测试专用的成功替身。

## 性能记录

- 最后一次桌面测试：100 节点「打开 + 首次渲染 + 缩放」约 270ms；200 节点约 480ms，详见 `desktop-performance.json`。
- 单元性能场景为同日期密集节点：本次记录的布局计算约 14ms / 34ms（100 / 200 节点）。
- 以上仅代表当前设备上的一次测量；包含测试调度开销的桌面耗时不是帧率承诺。
